# Setuav Studio

![Setuav Studio banner](images/studio_banner.png)

**Setuav Studio** is a desktop application for parametric UAV design and
analysis. You model the airframe, the propulsion system and the masses in one
project, drive them with formulas, and analyze the aircraft's aerodynamics,
powertrain and flight performance. Plugins extend every part of it.
